# EPF (KWSP) — Employer Contributions

- Standard split: employee 11%, employer 12–13% (employer rate depends on wage band)
- Employer contributes 13% if monthly wage ≤ RM5,000; 12% if monthly wage > RM5,000
- This RM5,000 threshold is evaluated per month, not annually — an employee earning
  RM4,900 in one month and RM5,100 the next can shift bands month to month.
- Foreign worker EPF (mandatory since Oct 2025): 2% employer + 2% employee — this is
  a new obligation many employers still overlook when budgeting for foreign hires.
- Late payment charge: EPF dividend rate + 1% per annum, minimum RM10 charge.
- EPF contributions are tax-deductible for the employee up to RM4,000/year — relevant
  when the Tax Agent discusses personal relief, not just the Payroll Agent's scope.

# SOCSO (PERKESO) & EIS — Employer Contributions

- Wage ceiling for both SOCSO and EIS contribution calculations: RM6,000/month
  (raised from RM4,000 in Oct 2024 — this is a relatively recent change and a common
  source of miscalculation in older payroll templates/spreadsheets)
- EIS registration is bundled with SOCSO registration — there is no separate
  standalone EIS registration step.
- Minimum wage as of 2026: RM1,700/month — payroll bases (and therefore SOCSO/EIS
  calculations) must reflect this floor, including for staff still on probation.

# PCB / MTD (Monthly Tax Deduction)

- Employers must deduct income tax monthly from employee salaries per LHDN's PCB schedule
- Calculation factors: marital status, working/non-working spouse, number of children,
  other dependents, zakat/approved donations, EPF contributions, insurance premiums
- LHDN publishes updated PCB tables annually — always confirm current-year table,
  do not reuse a prior year's schedule.

# Employer Registration (first hire)

- Four statutory bodies to register with: EPF (KWSP), SOCSO, EIS, LHDN (for PCB)
- EPF, SOCSO, EIS and LHDN registrations can generally be completed simultaneously
  once SSM business registration documents are in hand.
- Required upfront: SSM registration certificate + identification documents, before
  the first hire is made — sequencing matters (SSM registration is a prerequisite).

# Notes for Agent Reasoning

- A single new hire can trigger obligations across all three bodies (EPF, SOCSO/EIS,
  PCB) simultaneously — when reasoning about "I just hired someone," check all three,
  not just one.
- Foreign worker hires specifically trigger the EPF 2%/2% rule (Oct 2025) — this is
  easy to miss because older guidance (pre-Oct 2025) assumed foreign workers were
  EPF-exempt. Flag this explicitly if the user mentions a foreign hire.
- Rate/ceiling changes in this file have moved twice in 18 months (Oct 2024 SOCSO/EIS
  ceiling, Oct 2025 foreign-worker EPF) — treat these specific figures as the
  highest-volatility facts in the whole knowledge base.
